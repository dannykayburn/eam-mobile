5 — Bold ink collapsed bar
The collapsed row goes full ink (white text/chevron/segments-future), like the nav bar's own dark treatment — a deliberate, high-contrast control strip rather than a quiet gray one. Expanded map reverts to plain card white so the step list itself doesn't inherit the same intensity. Caveat found building this: pure ink IS the dark-mode page background (both #1A1A1F), so dark mode substitutes a dark gray instead — worth knowing if you like this in light mode, since it can't be literally "the same color" in both themes.
