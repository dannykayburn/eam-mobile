Activity Insert/Update Mode — layout options. Built from the full desktop field set (screenshot, update mode) using the same two shapes already established elsewhere: WO Insert Mode's "required grid up top, flat fields in containers below" split, and the existing hyperlink- popup shell (✕ header / scroll body / single footer Save). Activity's own number is locked (AUTOINCR-defaulted, never blank) so it renders as an identifier line, not a fillable field — it's never in the grid or a form-field row in either option. Both options carry Task Plan/Material List for completeness against the real field set, even though they're not part of the shipped simplified model yet. Try the Hired Labor checkbox on either option — Supplier/Labor Type unlock live.
Option 1 — No top pill, Trade in the grid
Trade sits as a normal required grid cell, paired with Assignment Status. Fewer distinct components on the screen — the grid is the only "classification" element, same job Type/Status does on WO Insert Mode.
