5 — Recommended combination
Resolves the §23 conflict structurally, same way §23.2 did for pills
Type field = Option 2's solid swatch fill (highest-legibility surface, and the one place a user is deliberately looking to confirm what they're working on). WO List row = Option 2's small dot, not a full badge — a dense card list is the wrong place for a 28px badge per row, and the dot is enough once the field label already says "Type." Step rail = Option 2's 3px left-edge bar, color only, no icon — matches the direct instruction that the rail should signal color, not add a second icon competing with the step name. All four Types (plus any admin-added custom code, e.g. Corrective) draw from the same curated 6-swatch set already scoped for the WO Type color picker — never a raw hex/color wheel — so this stays a narrowly-scoped 4th instrument next to §23.2's pill-fill, not a reopening of §23's 3-instrument rule itself.
